# 🏥 Intelligent Healthcare AI

AI-powered medical diagnosis system using NLP for symptom analysis.

## 🚀 Quick Start

**1. Start MongoDB**
```bash
mongod
```

**2. Backend**
```bash
cd backend
npm install
npm start
```

**3. Frontend**
```bash
cd frontend
npm install
npm start
```

**4. Open:** http://localhost:3000

## 🛠️ Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **NLP:** Natural, Compromise

## ✨ Features
- Symptom analysis
- Disease prediction
- Image upload
- User authentication
- Hindi/English support
